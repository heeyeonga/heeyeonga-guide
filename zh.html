02 | 住宿必需信息

家电使用方法也可查看住宿内放置的纸质指南。

免费高速 Wi-Fi
🌐

餐桌上有 Wi-Fi 二维码。

请用手机相机扫描二维码，即可连接 Wi-Fi。

燃气灶
  1. 请先按下燃气 电源键。屏幕上显示剩余时间后，才可以使用燃气灶。
  2. 将油烟机面板向外拉出，即可开启油烟机。
  3. 按下炉灶旋钮，并逆时针旋转到点火位置，直到火焰点燃。
  4. 当剩余时间闪烁时，按 ▲ UP 可增加更多时间。燃气可能会在短时间后自动关闭。
  5. 烹饪结束后，请务必将所有炉灶旋钮转到 OFF，将油烟机面板推回，并按电源键关闭燃气。
‼️

重要：定时器不会自动将炉灶旋钮转到 OFF。烹饪结束后，请务必确认所有旋钮都已转到 OFF。

洗衣机
👕

日常洗衣请使用 标准洗涤 程序。

  • 洗衣液请只倒入左侧格。
  • 洗衣液用量为 1杯，约30 ml，请勿过量。
  • 将旋钮转到 표준세탁 (标准洗涤)，然后按 开始/暂停 按钮。
  • 洗衣完成后，请取出衣物并移至烘干机。
烘干机
👕

日常烘干请使用 标准 程序。

  • 放入湿衣物，并加入 1张烘干纸。
  • 按下 电源，选择 标准，然后按 开始/暂停。
  • 烘干完成后，请取出衣物。
  • 每次使用后，请务必清理滤网上的绒毛。
  • 请只烘干少量衣物。标准烘干容量为 2.5 kg。
空调
🌡️

建议温度为 24-26°C。

✔️

空调遥控器放在电视下方，与电视遥控器放在一起。

空调已设置为制冷模式。请只使用以下按钮。

  • 按蓝色电源按钮可开启或关闭空调。
  • 按 ▲ / ▼ 可调节温度。
  • 按 풍향 (风向) 按钮可调整出风方向。
  • 外出时请关闭空调，以帮助节约能源、保护环境。
暖气控制
⚠️

请勿同时使用暖气和空调。否则可能导致电力过载、系统故障或火灾风险。

🌡️

请将温度保持在 20°C 到 24°C 之间。地暖升温可能需要 1-3小时。

  • 按 电源 按钮可开启或关闭暖气。
  • 使用 ▲ / ▼ 调节温度。
  • 只需要热水时，请使用 Hot Water Only / 仅热水 模式。
  • 离开房间时，请使用 Away / 外出 模式，可帮助节约能源。
  • 为防止故障，如有需要，房东可能会通过 IoT 远程调整暖气系统。
电视
📺

电视遥控器放在电视下方。

  1. 按遥控器左上方的红色电源键打开电视。
  2. 电视开机可能需要一点时间，请稍等片刻。
  3. 如需观看 Netflix 或 YouTube，请在电视开机后按遥控器下方的 Netflix 或 YouTube 按钮。
急救箱
🩹

急救箱在大卧室（有两张床的房间）梳妆柜/抽屉柜从上往下第二个抽屉里。

03 | 垃圾与清洁
马桶堵塞处理指南

如果马桶堵塞，请按照以下步骤使用房内放置的 Mr. Pung 马桶疏通器。

  1. 如图所示，将 CO₂ 气瓶 插入本体开口处。
  2. 将盖子盖紧，确认固定牢固。
  3. 将疏通器头部紧贴马桶排水口，并用力向下按压。
  4. 按下本体上方的圆形按钮，只按一次。
⚠️

注意事项：请在马桶内有足够水量的状态下使用。请将疏通器头部完全贴紧排水口，并在使用前再插入 CO₂ 气瓶后按下按钮。

❗

此工具利用强 CO₂ 压力疏通堵塞。请按照以上步骤只尝试一次。如果仍未解决，请联系房东。

室内厨余垃圾与分类回收指南
🍎

厨余垃圾 = 必须放入专用垃圾桶

请将厨余垃圾放入厨房水槽台面上的厨余垃圾桶。

🗑️

一般垃圾与可回收物 = 分开放入客厅垃圾桶

请将一般垃圾和可回收物分别放入客厅对应的垃圾桶。

  • 备用垃圾袋在水槽柜最下面的抽屉里。
  • 如果垃圾桶已满或担心异味，请参考下方 室外垃圾投放与分类回收。

厨余垃圾

  • 请将厨余垃圾收集在厨房水槽台面上的厨余垃圾桶内。
  • 使用后请把盖子盖紧。
  • 为避免异味，请至少每 2 天按照下方 室外垃圾投放与分类回收 的说明拿到室外丢弃。

一般垃圾

一般垃圾是指除厨余垃圾和可回收物以外的不可回收垃圾。

  • 一般垃圾桶内已经套好垃圾袋。请只放入一般垃圾。
  • 请勿与可回收物混在一起。
  • 如果垃圾桶已满，请扎紧垃圾袋并拿到室外丢弃。

可回收物

  • 纸箱和纸袋：请压平后放在一处。
  • 外卖餐盒请务必简单冲洗后再分类放置。
室外垃圾投放与分类回收
🚪

请投放在建筑入口外、墙边标示的位置。

投放位置

  • 可回收物： 放在标示的可回收物位置。
  • 一般垃圾： 扎紧垃圾袋后，放在标示的一般垃圾位置。
  • 厨余垃圾： 将扎好的袋子放入绿色厨余垃圾桶。

厨余垃圾

  1. 扎紧厨余垃圾袋。
  2. 打开绿色垃圾桶盖。
  3. 将袋子放入桶内。
  4. 盖好盖子。

一般垃圾 / 可回收物

仅在需要时拿到室外丢弃。

  • 一般垃圾： 扎紧垃圾袋后放在标示位置。
  • 纸箱 / 纸袋： 放在一起。
  • 塑料袋 / 塑料： 请先放出来。
  • 易拉罐 / 纸类 / 其他可回收物： 按种类分开。
  • 玻璃、易拉罐、纸类等请分别装入不同袋子。
