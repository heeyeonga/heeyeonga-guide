02 | 滞在に必要な情報

家電の使い方は、宿泊施設内に置いてある印刷ガイドでも確認できます。

無料高速 Wi-Fi
🌐

ダイニングテーブルの上に Wi-Fi QRコードがあります。

スマートフォンのカメラで読み取ると接続できます。

ガスコンロ
  1. まずガスの 電源ボタン を押してください。画面に残り時間が表示されると、ガスコンロを使用できます。
  2. フードのパネルを引き出すと、フードが ON になります。
  3. 使用するコンロのつまみを押し込み、反時計回りに点火位置まで回して、火がつくまで少し待ちます。
  4. 残り時間が点滅したら、▲ UP を押すと時間を追加できます。しばらくするとガスは自動で止まる場合があります。
  5. 調理後は、すべてのコンロのつまみを必ず OFF にし、フードのパネルを戻して、ガスの電源ボタンを押して止めてください。
‼️

重要：タイマーではコンロのつまみは自動で OFF になりません。調理後は必ずすべてのつまみが OFF になっているか確認してください。

洗濯機
👕

普段の洗濯には 標準洗濯 コースをご利用ください。

  • 洗剤は左側の投入口のみに入れてください。
  • 洗剤の量は 1杯、約30 ml までにしてください。
  • ダイヤルを 표준세탁 (標準洗濯) に合わせ、スタート/一時停止 ボタンを押してください。
  • 洗濯が終わったら、洗濯物を取り出して乾燥機へ移してください。
乾燥機
👕

普段の乾燥には 標準 コースをご利用ください。

  • 濡れた洗濯物を入れ、乾燥機シートを1枚入れてください。
  • 電源を押し、標準を選択してから スタート/一時停止 を押してください。
  • 乾燥が終わったら、洗濯物を取り出してください。
  • 使用後は毎回、フィルターのほこりを必ず取り除いてください。
  • 少量のみご利用ください。標準乾燥容量は 2.5 kg です。
エアコン
🌡️

推奨温度は 24-26°C です。

✔️

エアコンのリモコンはテレビの下に、テレビのリモコンと一緒にあります。

エアコンはすでに冷房モードに設定されています。下記のボタンのみご使用ください。

  • 青い電源ボタンでエアコンをオン/オフできます。
  • ▲ / ▼ ボタンで温度を調節できます。
  • 풍향 (風向) ボタンで風向きを変更できます。
  • 外出時は環境保護のため、エアコンを消してください。
暖房操作
⚠️

暖房とエアコンを同時に使用しないでください。電力過負荷、システム不具合、火災リスクの原因になる場合があります。

🌡️

温度は 20°C-24°C の間に設定してください。床暖房が暖まるまで 1-3時間 かかる場合があります。

  • 電源 ボタンで暖房をオン/オフできます。
  • ▲ / ▼ で温度を調節できます。
  • お湯だけが必要な場合は Hot Water Only / 温水専用 モードを使用してください。
  • 外出時は Away / 外出 モードを使用すると省エネになります。
  • 故障防止のため、必要に応じてホストが IoT で暖房を遠隔調整する場合があります。
テレビ
📺

テレビのリモコンはテレビの下にあります。

  1. リモコン左上の赤い電源ボタンを押して、テレビをつけてください。
  2. テレビがつくまで少し時間がかかる場合があります。しばらくお待ちください。
  3. Netflix または YouTube を見る場合は、テレビがついた後、リモコン下部の Netflix または YouTube ボタンを押してください。
救急箱
🩹

救急箱は大きい寝室（ベッドが2台ある部屋）のタンス上から2段目の引き出しにあります。

03 | ゴミ・清潔
トイレ詰まり対処ガイド

トイレが詰まった場合は、室内に置いてある Mr. Pung トイレ用プランジャー を下記の手順で使用してください。

  1. 図のように CO₂ カートリッジ を本体の差し込み口に入れてください。
  2. ふたをしっかり閉めてください。
  3. プランジャーの先端をトイレの排水口に密着させ、しっかり下に押してください。
  4. 本体上部の丸いボタンを 1回だけ 押してください。
⚠️

注意事項：便器内に十分な水がある状態で使用してください。プランジャーの先端を排水口にしっかり密着させ、CO₂ カートリッジは使用直前に入れてからボタンを押してください。

❗

この道具は強い CO₂ 圧力で詰まりを解消するものです。上記の手順は1回だけお試しください。解消しない場合はホストにご連絡ください。

室内の生ゴミ・分別ガイド
🍎

生ゴミ = 必ず専用ゴミ箱へ

生ゴミはキッチンのシンク上にある生ゴミ用ゴミ箱に入れてください。

🗑️

一般ゴミ・リサイクル品 = リビングのゴミ箱に分別

一般ゴミとリサイクル品は、それぞれリビングのゴミ箱に分けて入れてください。

  • 予備のゴミ袋はシンク下収納の一番下の引き出しにあります。
  • ゴミ箱がいっぱいになった場合や、においが気になる場合は、下の 屋外のゴミ出し・分別 を参考にしてください。

生ゴミ

  • 生ゴミはキッチンのシンク上にある生ゴミ用ゴミ箱にためてください。
  • 使用後はふたをしっかり閉めてください。
  • におい防止のため、少なくとも2日に1回は下の 屋外のゴミ出し・分別 を参考にして外に出してください。

一般ゴミ

一般ゴミとは、生ゴミとリサイクル品を除いた、リサイクルできないゴミのことです。

  • 一般ゴミ用のゴミ箱には、あらかじめゴミ袋がセットされています。一般ゴミのみ入れてください。
  • リサイクル品と混ざらないように分別してください。
  • ゴミ箱がいっぱいになった場合は、袋を結んで屋外に捨ててください。

リサイクル品

  • 段ボール・紙袋は平らにして、一か所にまとめて置いてください。
  • フードデリバリーの容器は、必ず軽くすすいでから分別してください。
屋外のゴミ出し・分別
🚪

建物入口を出てすぐ、壁側の表示された場所に出してください。

ゴミ出し場所

  • リサイクル品： 表示されたリサイクル品の場所に置いてください。
  • 一般ゴミ： 袋を結んで、表示された一般ゴミの場所に置いてください。
  • 生ゴミ： 結んだ袋を緑色の生ゴミ用ゴミ箱に入れてください。

生ゴミ

  1. 生ゴミの袋を結んでください。
  2. 緑色のゴミ箱のふたを開けてください。
  3. 袋を中に入れてください。
  4. ふたを閉めてください。

一般ゴミ / リサイクル品

必要な場合のみ屋外へ出してください。

  • 一般ゴミ： 袋を結んで、表示された場所に置いてください。
  • 段ボール / 紙袋： まとめて置いてください。
  • ビニール / プラスチック： 先に外へ出してください。
  • 缶 / 紙 / その他リサイクル品： 種類ごとに分けてください。
  • ガラス、缶、紙などは、それぞれ別の袋に分けて入れてください。
